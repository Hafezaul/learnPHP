# Object Type

Jenis data yang menyimpan instans atau wujud nyata dari sebuah class (cetak biru atau blueprint), yang berisi gabungan variabel (properti) dan fungsi (metode). 

Konsep Dasar Object Type
1. Class: Cetak biru atau templat.
2. Object: Hasil cetak (instansiasi) dari class menggunakan kata kunci new.
3. Properti: Variabel di dalam class yang menyimpan data objek.
4. Metode: Fungsi di dalam class yang menentukan perilaku atau tindakan objek.
