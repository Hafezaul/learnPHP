# Construct 

Construct adalah metode khsuus secara otomatis dijalankan pertama kali saat sebuah objek dibuat dari sebuah kelas.

### Fungsi Construct 

1. Inisialisasi nilai awal: Mengisi properti objek secara langsung saat objek pertama kali dipanggil.
2. Menghemat kode: Tidak perlu memanggil fungsi pengisi data (seperti set_nama()) secara terpisah.
3. Penulisan: Menggunakan nama khusus yaitu __construct()


###### Contoh
```php
<?php 

class Produk{ 
    public $judul = "judul", 
           $penulis = "penulis", 
           $penerbit = "penerbit", 
           $harga = 0;

    public function __construct($judul = "Unknown", $penulis = "Unknown", $penerbit = "Unknown", $harga = 0){
        $this->judul = $judul;
        $this->penulis = $penulis;
        $this->penerbit = $penerbit;
        $this->harga = $harga;
    }
    public function getLabel(){ 
        return $this->penulis. ", " . $this->penerbit; 
    }
}

$produk1 = new Produk("Naruto", "Masashi Kishimoto", "Shueisha", 10000);
$produk2 = new Produk("Mobile Legends", "Moonton", "Moonton", 25000);
$produk3 = new Produk("Dragon Ball"); 

echo "Komik : " . $produk1->getLabel();
echo "<br>";    
echo "Game : " . $produk2->getLabel();
echo "<br>";
echo "Komik : " . $produk3->getLabel();
?> 
```
